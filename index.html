PgNumber.js

Librería en JavaScript puro (Vanilla ES6+) ultraligera sin dependencias para restringir, validar y formatear entradas numéricas en tiempo real.

Sin Dependencias UMD Compatible < 2 KB Minificado

Instalación e Integración

Inclusión Directa (HTML)

Descarga el archivo e inclúyelo mediante etiqueta script estándar:

<script src="pgnumber.js"></script>

Importación ES6 / Bundlers

Importación modular para entornos como Vite, Webpack o Rollup:

import PgNumber from './pgnumber.js';

Playground Interactivo al Instante

Configuración en Tiempo Real

Los cambios aplican y formatean automáticamente el campo mediante blur.

Código Generado

new PgNumber('#miInput', { decimals: 2, separator: '.', negative: false, parse: true, selectize: true });
<input type="text" data-pgnumber-decimals="2" data-pgnumber-separator="." data-pgnumber-negative="false" data-pgnumber-parse="true" data-pgnumber-selectize="true" />

Opciones de Configuración

Las opciones pueden configurarse globalmente mediante la API JS o individualmente sobre cada elemento HTML con atributos `data-pgnumber-*`.

Propiedad JS Atributo HTML Data Tipo Por Defecto Descripción
selector - string "" Selector CSS para activar la delegación de eventos en elementos dinámicos.
negative data-pgnumber-negative boolean false Permite o prohíbe el ingreso del signo negativo (`-`).
decimals data-pgnumber-decimals number 2 Número máximo de lugares decimales permitidos.
separator data-pgnumber-separator string "." Carácter utilizado como separador decimal (`"."` o `","`).
parse data-pgnumber-parse boolean true Aplica normalización `toFixed()` en el evento `blur`.
selectize data-pgnumber-selectize boolean true Selecciona todo el texto del campo automáticamente en el evento `focus`.

Ejemplos Prácticos

1. Configuración por Atributos HTML Data

Sobrescribe la configuración global de JavaScript utilizando atributos HTML en cada elemento.

Acepta negativos, 4 decimales y usa coma (,) como separador. 
<input type="text" class="demo-input" data-pgnumber-negative="true" data-pgnumber-decimals="4" data-pgnumber-separator="," />
<script>
  new PgNumber('.demo-input');
</script>

2. Delegación en Formularios / Tablas Dinámicas

Permite escuchar campos creados en tiempo de ejecución sin re-inicializar el plugin.

// Escucha sobre el contenedor padre (#containerDinamico)
new PgNumber('#containerDinamico', {
  selector: '.input-dinamico',
  decimals: 2,
  separator: '.'
});

API y Métodos

new PgNumber(target, [options])

Crea e inicializa una nueva instancia de la librería sobre los elementos especificados.

  • target: Puede ser un string (selector CSS), un HTMLElement, un NodeList o un Array de elementos.
  • options: Objeto de configuración opcional.

instance.destroy()

Elimina los listeners de eventos registrados sobre los contenedores y libera referencias en memoria. Indispensable al desmontar componentes en aplicaciones SPA (React, Vue, Angular).
